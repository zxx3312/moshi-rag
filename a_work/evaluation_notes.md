## 重现派生评分

在仓库根目录运行（另一轮只需改 RUN）：

```bash
RUN=a_work/results/replay/b_q1_20_gen_v5
python3 a_work/eval_with_b.py "$RUN" --ref 15f0e0246cc91443bd74b477ccee941432794ef6 \
```
