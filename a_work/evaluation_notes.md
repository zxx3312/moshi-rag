## 2. 支持性：可以得到什么保守结论

所有非 Oracle 配置仍有声明待复核，因此官方整体 Structured UCR 为 null。
112/1032=10.9% 与 347/928=37.4% 只是各自已评分声明的比例，不能冒充整体 UCR。

沿用 B scorer 已有的上下界定义，对当前已登记声明汇总：
下界 = 已知无依据 / 全部登记声明；上界 =（已知无依据 + 待复核）/ 全部登记声明。
这只描述当前 gold/映射口径下缺失声明标签的可能取值，不改变官方 null，也不引入新置信区间。

| 配置 | 已登记声明数 | 支持性错误率下界–上界 |
|---|---|---|
| Wait-All / Fixed Progress | 958 | 36.2%–39.4% |
| Time-Only | 952 | 53.6%–56.8% |
| First-Evidence | 946 | 71.1%–74.5% |
| Prompt | 1226 | 9.5%–36.5% |
| LoRA | 1353 | 8.3%–32.0% |

即使把主方法待复核声明全按无依据算，Prompt/LoRA 的上界仍低于 Time-Only、First-Evidence 的下界。
这是 H2 在**已登记结构化声明范围**的较强描述性证据。
LoRA 与 Wait-All 的范围也分离，但主方法会登记更多中间事实，分母和生成路径不同，
不能将其解释为相同事实预算下的纯策略效果。Prompt 与 Wait-All 的范围仍有重叠。

范围不覆盖正文未登记事实、否定/改写理解错误或错误关系映射；因此仍不能宣称完整自由回答的
幻觉率已被测准。也没有做配对置信区间，不能把范围分离当作总体统计显著性检验。

“答案值对”与“说出时有完整证据及引用”不同：First-Evidence 有 425 条 answer_complete，
但只有 231 条 grounded_complete，另 194 条已知答案值正确却支持不完整；Time-Only 对应 97 条。
Prompt 和 LoRA 也分别有 81、72 条此类运行。当前主方法仍会误放行或引用不全，尚非可靠性问题已解决。
